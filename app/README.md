# Сервер картинок 2.0

Веб-сервис для загрузки, хранения и управления изображениями.

## Функциональность

- Загрузка изображений (JPG, JPEG, PNG, GIF)
- Просмотр списка загруженных изображений
- Удаление изображений
- Пагинация списка изображений
- Резервное копирование базы данных

## Требования

- Docker
- Docker Compose

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd imageHoster
```

2. Запустите сервисы:
```bash
docker compose up --build
```

3. Откройте в браузере:
```
http://localhost:8080
```

## Использование

### Загрузка изображений

1. Откройте главную страницу
2. Нажмите "Выберите файл"
3. Выберите изображение (JPG, JPEG, PNG или GIF)
4. Нажмите "Загрузить"

### Просмотр списка изображений

1. Нажмите "Список изображений" на главной странице
2. Используйте пагинацию для навигации по списку
3. Нажмите на имя файла для просмотра изображения
4. Нажмите "Удалить" для удаления изображения

### Резервное копирование

Для создания резервной копии базы данных:

```bash
docker compose exec app python backup.py
```

Резервные копии сохраняются в директории `backups` с именем в формате `backup_YYYY-MM-DD_HHMMSS.sql`.

Для восстановления из резервной копии:

```bash
docker compose exec app python backup.py restore backups/backup_YYYY-MM-DD_HHMMSS.sql
```

## Структура проекта

```
project/
├── app.py                # Python-бэкенд (FastAPI)
├── backup.py            # Скрипт резервного копирования
├── requirements.txt     # Зависимости Python
├── Dockerfile          # Dockerfile для Python-бэкенда
├── docker-compose.yml  # Конфигурация Docker Compose
├── nginx.conf         # Конфигурация Nginx
├── init.sql           # SQL-скрипт инициализации базы данных
├── images/            # Папка для хранения изображений
├── logs/              # Папка для логов
├── backups/           # Папка для резервных копий
├── static/            # Статические файлы (CSS/JS)
└── templates/         # HTML шаблоны
```

## Технические детали

- Backend: FastAPI
- База данных: PostgreSQL
- Веб-сервер: Nginx
- Контейнеризация: Docker
- Логирование: loguru
- Максимальный размер файла: 5MB
- Поддерживаемые форматы: JPG, JPEG, PNG, GIF
